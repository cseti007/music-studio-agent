# Agent workflow

Read `CLAUDE.md` for the shared agent workflow and `docs/knowledge.md` for
evidence and engineering guidance. These instructions apply to every agent,
regardless of model or host. Existing user instructions and approvals take
precedence; do not ask again for authorized work.

State whether direct audio audition is available. Measurements and file exports
cannot establish musical quality or listening approval. Keep first renders as
drafts, preserve scoped feedback, and use `tools/review_delivery.py` before
calling a version approved for delivery. Never fabricate listening evidence.
